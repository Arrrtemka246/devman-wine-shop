# Новое русское вино

Сайт винодельни из урока «Продаём элитное вино» курса Devman.
Ассортимент загружается из Excel и отображается по категориям. Возраст
винодельни рассчитывается от 1920 года, форма слова «год» выбирается автоматически.
У товаров без сорта винограда соответствующая строка скрыта; отметка акции
в таблице включает значок «Выгодное предложение».

## Установка и запуск

Нужен Python 3.11 или новее. В терминале в папке проекта:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Откройте http://127.0.0.1:8000/index.html.
Чтобы остановить сервер, нажмите Ctrl+C.

## Обновление ассортимента

Измените `wines.xlsx`, сохраните файл и перезапустите программу. Перезагрузите
страницу браузера. Файл `index.html` создаётся заново из `template.html` при запуске;
постоянные изменения вёрстки вносите в шаблон.

Колонки таблицы: `Категория`, `Название`, `Сорт`, `Цена`, `Картинка`, `Акция`.
`Цена` — число в рублях, `Картинка` — имя файла в папке `images`.
Поля `Сорт` и `Акция` можно оставить пустыми. Названия категорий произвольны:
они берутся из таблицы. Для акции укажите `Выгодное предложение`.

Другой файл и порт можно передать параметрами:

```sh
python main.py --data wines.xlsx --port 8000
```

Сгенерировать страницу без запуска сервера:

```sh
python main.py --build-only
```

Вывести продукцию по категориям в терминал:

```sh
python main.py --build-only --show-products
```
